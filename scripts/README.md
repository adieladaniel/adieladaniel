# Generators

Every animated graphic in the profile README is generated by a script here and
written to `../assets/`. All outputs are plain SVG with CSS animation, so they
render on github.com when referenced by relative path.

| Output | Generator | Notes |
| --- | --- | --- |
| `assets/portrait.svg` | `python scripts/make_portrait.py PATH_TO_PHOTO` | Halftone dot portrait. Fixed random seed, so output is deterministic. |
| `assets/journey.svg` | `python scripts/make_journey.py` | Reads `scripts/journey.yml`. Needs `pip install pyyaml`. |
| `assets/terminal.svg` | `python scripts/make_terminal.py` | Typing intro. Edit the `LINES` list in the script. |
| `assets/now-building.svg` | `python scripts/now_building.py` | Calls the public GitHub API. Uses `GITHUB_TOKEN` if set. Standard library only. |

`assets/now-building.svg` is refreshed daily by `.github/workflows/now-building.yml`.
If the workflow cannot push, enable Settings > Actions > General > Workflow
permissions > Read and write permissions.

## Privacy: the photo stays outside the repo

`make_portrait.py` reads the photo from the path you pass on the command line,
for example `D:\photos\profilepic.png`. The photo is never copied into this
repository and never embedded in the SVG. The output contains only generated
vector circles. `.gitignore` blocks `*.png`, `*.jpg`, `*.jpeg`, `*.webp` and a
`private/` folder so a source photo cannot be committed by accident.

Requirements for the portrait script: `pip install pillow numpy scipy`.
